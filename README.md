# Little Lemon Restaurant - Table Reservation App

Responsive restaurant website with online table booking. Built with React as a practice project for modern front-end development.

**Demo:** https://github.com/maru-catherina/FEDCapstone.
**Figma Design:** Based on Little Lemon brand concept


## Features
- Clean landing: Header, Hero, Weekly Specials, About, Footer
- Navigation with React Router: Home / Reservation / Login
- **Reservation System:**
    - Choose Date (date picker)
    - Choose Time (17:00, 18:00 etc.)
    - Number of guests
    - Occasion (Birthday, Anniversary)
    - Client-side validation
- Fully responsive (mobile, tablet, desktop)
- Branded UI - yellow / dark green palette

## Tech Stack
- React.js (Create React App)
- React Router DOM
- JavaScript ES6+, Hooks: useState, useEffect, useReducer
- HTML5 Semantic, CSS3 Flexbox / Grid
- GitHub Pages for deployment
